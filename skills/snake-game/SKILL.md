# 单文件贪吃蛇

1. 先调用 `mcp_snake_spec` 获取独立于本 Skill 的验收标准。
2. 只创建一个 HTML 文件；CSS 和 JavaScript 必须内联，不引用 CDN。
3. 游戏状态至少包含：蛇身、当前方向、下一方向、食物、分数、最高分、运行状态。
4. 输入支持方向键和 WASD，必须拒绝 180 度直接反向。
5. 用 `requestAnimationFrame` 负责渲染调度，用累计时间控制固定移动间隔；不要让蛇按显示器刷新率移动。
6. 食物不得生成在蛇身上。撞墙或撞到自身时进入结束状态。
7. 页面上提供可点击按钮，并支持空格键开始、暂停或重新开始。
8. 完成后调用 `mcp_validate_snake_html`。若检查未通过，读取文件、修复，再验证。
9. 最终回复给出文件相对路径、控制方式和验证结果，不要声称执行过未执行的检查。
